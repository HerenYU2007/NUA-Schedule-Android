## 1.1.21 设置保存与登录会话状态

教务版的“登录与后台更新”设置使用同步提交并回读校验，返回设置页后会保留“保存登录会话”和“后台自动更新课表”的勾选状态。设置页会显示登录会话 Cookie 是否检测到及最近检测时间，只显示状态，不显示 Cookie 内容。成功获取学校课表后自动刷新检测；强制清除登录时会清除旧状态。

## 1.1.18 提醒、倒计时与后台更新

主界面和小组件会显示下一节课倒计时；课程进行中显示距离下课时间，每30秒刷新。两版均可在“上课提醒设置”中选择提前5、10、15、20或30分钟的系统通知。通知权限或精确闹钟权限被系统拒绝时，App会按系统可用能力工作，不会把权限当作登录凭据保存。

教务版的“保持登录与后台更新”是可选功能：只保留学校 WebView 的登录 Cookie，不保存账号密码；开启后系统约每6小时在有网络且电量允许时启动一次既有安全同步流程。后台同步成功才替换课表，并保留当前开学时间；会话过期、网络失败或解析失败均保留原课表并要求用户重新登录。系统省电策略和后台启动限制可能延迟更新。

## 1.1.17 获取失败与备用通道

自动获取按当前页面实际识别的通道工作：首个通道失败时只切换到另一个学校通道一次；任一通道成功得到课表预览就结束。两个通道都失败会立即显示“获取失败，请稍后重试”，不会清空或覆盖原课表。旧页面、下载和脚本的重复回调不会重复重试；登录认证等待和本地导入已下载 XLS 不触发网络通道切换。导出等待与页面备用读取均有明确上限，避免无提示长时间等待。

原生 Android 课表应用，默认使用空课表，不再附带个人课程数据。登录同步或导入学校 XLS 并确认后，才显示你的课程；按要求不导入“军事技能”。

## 功能

- 今日课程：显示时间、课程、地点、理论/实践、教师与实时课程状态。
- 日期切换：支持前后一天、前后整周、回到今天和日历选日。
- 本周课表：按日期列出当周所有课程。
- 桌面小组件：默认仍为4×2，可双向调整大小；按每个组件的实际尺寸和横竖屏布局显示0—3节完整课程，小空间提示未显示的课程数量，点击打开完整课表。手机正常宽度使用时间/课程同一行、地点下一行，课程列表从顶部往下排列，保留完整日期、周次/数量信息；平板沿用原分行样式及顶部排列。状态保持最右侧居中。显示“正在进行/未开始”，自动隐藏当天已结束课程；可用“‹ 今 / 明 ›”切换今天与明天，每晚22:00自动显示明日课表，午夜自动回到当天。
- 小组件选择器：提供与实际课表一致的预览图和预览布局，便于添加前确认样式。
- 教务同步（试用）：用户完成学校 CAS 登录后，自动按“教务系统（新）→进入首页→培养管理→我的课表→学期课表”查找和读取，不会进入选课入口；读取成功后预览确认导入，军事技能仍会排除。
- 登录跳转：保留学校原页面的 SSO 提交，新窗口实际加载后才显示，避免直接切换到未加载的白屏窗口；菜单去重、页面内教务框架识别及课表查询均自动执行。
- 教务首页识别：已按用户提供的 `https://jwnew.nua.edu.cn/jsxsd/framework/xsMain.jsp` 识别首页；地址本身不代表认证成功，须同时有可见教务菜单且无密码表单。遇到教务密码登录页时保留 Cookie 返回门户自动重试一次单点登录，仍失败则停止并保留原课表，不在教务页面提交账号密码。
- 入口兼容：同一入口只允许一个等待加载的新窗口，允许临时 `about:blank#...` 占位页。学校 HTTP GET 跳转仅尝试同址 HTTPS，保留参数编码，不重放 POST、不降级明文、不绕过证书。失败诊断展示脱敏协议、域名、路径和 WebView 版本，便于定位。
- SSO 回调保护：同一路径下不同查询参数的初始入口和认证回调分别处理，完整请求身份只用摘要在当前窗口内存中去重，不能用去掉参数的诊断地址判断重复。有限重复只取消本次 HTTP 跳转，不中断已排队的 HTTPS 请求；每个窗口最多转换 8 个不同 GET 请求、合并 8 次重复，超限才停止循环。摘要和票据不输出到诊断。
- 1.1.9 每次手动获取都重新登录：打开同步页、点击“重新获取课表”或“学校入口”都会先取消旧下载、销毁旧页面、清除本 App WebView 的 Cookie、缓存、历史和网页本地存储；等 Cookie 清除完成才加载学校入口。已有课表保留，确认导入后才替换。一次新登录后的自动跳转和导出保留当次会话，不在中途反复清空。
- 取课诊断只增加可读页面、不可读框架、表格数量和课程/时间列存在与否，不复制页面正文。菜单匹配允许装饰箭头和明确的 title/aria-label，展开后继续查找下级入口；仅在个人课表页面点击实际存在的列表视图控件。
- 1.1.7 按用户提供的教务首页截图补齐“学期课表”叶子入口：已展开时优先叶子，点击后不收起“我的课表/培养管理”；识别这条分支时不绕入“课程课表查询、调停课查询、各类课表查询”或选课。首页侧栏文字不会触发主页的其他列表/查询控件。
- 优先 XLS 导出：在确实有个人课表数据的页面查找“导出课表”等明确按钮，只请求一次；接收学校实际提供的下载地址，复用登录 Cookie 通过教务 HTTPS 下载。不会猜测导出接口、重放登录票据或重构 POST 表单。20 秒没有下载请求时尝试页面读取。
- XLS 备用导入：打开同步页完成本地登录清理后，可直接选择已下载的学校 XLS，无须完成网页登录。格式按用户确认的原始二进制导出适配：星期列决定上课日，课程块的明确周次、节次、教师、地点决定内容；跨时间格重复课程去重，军事技能排除。支持课程列表格式的 XLS；不支持 HTML 假 XLS、XLSX、加密文件或任意第三方课表模板。
- 文件仅在内存中读取，最多 5 MB；下载允许教务直连 HTTPS 或当前教务页对应的学校 WebVPN HTTPS 课表路由，限标准端口，保留系统证书检查，重定向有上限，不输出 Cookie、下载参数、文件名或文件正文到诊断。格式失败或取消预览不会覆盖原课表。
- 网页周视图为备用读取：按星期列和课程块的显式节次识别，支持多个周次/地点分段和跨格去重；无法确认的结构提示核对，不把第一二节等行标签误作课程真正起止节次。
- 1.1.8 按最新截图识别“学期理论课表”及只有“导出”文字的按钮；通用按钮仅限同一文档确有课表结构时使用。教务站内保持首页和框架，不把个人中心等 iframe 提升为主页面；只读 DOM 遍历忽略隐藏框架和已知个人信息设置页。若当前主页面已误入个人信息，只返回教务首页一次，不读写或提交资料表单，反复返回则停止。
- 同步课表支持分段教室、单双周、周次列表，并随导入课程扩展周次范围。未识别时间、教室错位或疑似分页会提示核对，不会静默猜测。
- 自动周次：导入确认和主界面均可选择“开学时间”，保留具体日期，将该日期所在周（周一至周日）设为第1周，显示对应日期范围。修改后课表和小组件一起重新计算；旧版保存的周一作为兼容开学日期，升级不会改变原周次。空课表时不显示学期周次。支持确认后清空已导入课表，不会退回旧版内置课程。
- 学校时间统一按 Asia/Shanghai 计算。

## 在 E 盘构建

1. 安装 JDK 17。
2. Android SDK 位于 `E:\AndroidSDK`，需要 Android 35 SDK Platform 和 Build Tools 35.0.0。
3. 用 Android Studio 打开本目录，或在 PowerShell 中运行：

   ```powershell
   .\build-on-e.ps1
   ```

`build-on-e.ps1` 使用 `E:\GradleCache` 中已有的 Gradle 8.7 与依赖缓存；首次构建可能联网补齐缺失依赖。Android 用户缓存保留在本项目目录中，构建临时目录使用 `E:\AndroidBuildTemp`。调试 APK 生成于 `app\build\outputs\apk\debug\app-debug.apk`。

## 教务同步使用与限制

1.1.16：补齐外网导航脚本的教务域名识别，使 WebVPN 首页中的学期课表框架也能自动点击实际导出按钮；导出请求后保留展开的父菜单。外网教务密码表单、CAS 和个人信息页继续受到保护，导出不可用时也支持网关周视图备用读取。诊断版本号改为读取实际安装版本，下载状态仅记录 HTTP 状态、固定类型分类、字节数及异常类型，不记录响应正文或请求凭据。已在用户的 HONOR 60 / Android 14 / Huawei WebView 14.0.0.370 外网 USB 现场自动获取并打开 XLS 导入预览，识别11门课程、138次上课且排除军事技能；没有代替用户选择开学时间或确认保存。

1.1.15：外网经学校 `v.nua.edu.cn/https/<路由>/...` 进入教务后，导出的 XLS 不再因域名不同被误拦截。只允许当前打开教务页对应的同一网关路由下 `/jsxsd/xskb/` 的实际下载；新窗口可使用其来源页。Cookie 按每一跳的实际 URL 获取，Referer 使用同一路由的教务首页且不携带查询或片段；不把外网请求改到校园网直连，也不把校园网请求转到外网路由。网关路径不硬编码、不写入诊断。此修改已通过模拟下载与解析测试，真实外网导出仍须手机验证。

1.1.14：登录后的自动导航、导出与读取阶段显示带加载动画的“正在获取课表，请稍后”弹窗。等待用户认证时不遮挡登录，进入导入预览、连接失败或超时时自动关闭；也可隐藏提示而继续获取，同一次获取不会反复弹出。离开同步页不残留弹窗，重新获取时重新提示。个人版及两版小组件不变。

1. 点“登录教务系统并同步课表”，在学校官方登录页面自行输入账号、密码并完成验证码或其他认证。
2. 登录完成后 App 自动查找门户中的教务系统（新）、进入首页，再按截图确认的“培养管理→我的课表→学期课表”导航。请等待顶部自动获取进度。PC 门户使用桌面浏览器标识和可缩放视口。
   未开启“保存登录会话”时，每次打开同步页会先清空本应用旧登录 Cookie，通过门户重新认证；开启后会优先复用已检测到的学校会话。需要强制重新认证时使用“退出登录”或“学校入口·清空登录并重连”。必须通过门户单点登录建立教务会话，不要在教务本地密码登录页重新输入账号密码。没有真实会话时该首页网址也可能返回登录页。
3. 在学期课表页优先请求实际导出按钮、读取 XLS；12 秒未收到下载事件则尝试当前页面读取，备用读取最多再等待8秒。有课程列表和“全部”分页选项时会尝试展开，同步不会任意更改所选学期，也不会自动进入选课。单个学校通道最多等待75秒；失败才尝试另一个通道一次，两次均失败立即提示“获取失败，请稍后重试”。失败可点“重新获取课表（清空登录）”，重新完成官方登录。上方“学校入口”同样清空登录并重连。也可用“导入已下载的 XLS”选择学校导出的文件，无须完成网页登录。诊断可帮助区分卡在菜单、下载或表格格式。
4. 在预览中核对课程和提示，按学校校历选择开学时间；该日期所在的周为第1周，再确认导入。取消不会替换现有课表。导入后小组件同步使用新数据，也可在主界面修改开学时间。

同步不是无人值守的账号密码登录，也不是后台定时联网抓取。App 不读取或保存原始账号密码；学校登录 Cookie 和网页存储会留在本 App 的 WebView 中以维持会话，可用“退出登录”清除。导航仅检查教务页面是否存在密码控件，不读取控件值；不会在 CAS 页面、密码表单或非学校 HTTPS 页面执行菜单操作和课表提取，没有原生 JavaScript 桥接。App 已关闭 Android 备份与明文网络访问。

教务同步版1.1.12起更名为“南艺电子课表”，桌面名称、App内标题、小组件名称/说明、添加提示和同步诊断统一使用新名称。Android包名仍为1.1.2起的 `cn.nua.wenguan.schedule`，签名不变，可直接覆盖旧同步版并保留已导入课程、开学时间和组件数据；无需卸载重装。个人版 `com.yubohang.schedule` 仍叫“南艺文管课表”，本次未修改。两版可共存，不互相覆盖，也不互相继承数据。

目前已完成构建、静态检查、课表解析、导航脚本、SSO 新窗口及双通道失败策略回归保护测试，并在上述 Android 手机的外网环境现场完成学校登录后自动导航、XLS 导出、下载、解析及导入预览验证，**不能保证所有学校页面版本、网络和设备都已适配**。实际门户菜单、跨域框架、验证码、内网限制或表格结构变化可能需要进一步适配。不能识别时原课表继续保留。诊断只在当前同步页面内存中保留：不抓取密码、Cookie、登录票据、页面正文或脚本错误正文，网址查询参数和片段不会记录；复制诊断由用户自行操作。

双节完整时间来自用户提供的节次图；单节和跨三节时间按相邻时段推算，可能与学校单节铃声有差异，需以校方公布时间为准。小组件使用系统非精确闹钟，省电策略可能延迟22:00切换及状态刷新；今天/明天用左右按钮切换，并非桌面横向滑动手势。
